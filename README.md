# 🏆 CodeCal | Live & Upcoming Coding Contests Calendar

![Vite](https://img.shields.io/badge/Vite-5-purple?logo=vite)
![License](https://img.shields.io/badge/License-MIT-green)
![Author](https://img.shields.io/badge/Author-Yash_Dangi-orange)

**CodeCal** is a modern, responsive web application for competitive programmers, computer science students, and developers to track live and upcoming coding contests, hackathons, and speed rounds across **CodeChef**, **HackerEarth**, **Topcoder**, **Codeforces**, **LeetCode**, and **AtCoder**.

Authored by **[Yash Dangi](https://github.com/dangiyash)**.

---

## 🔥 Features

- 📡 **Multi-Platform Contest Feed**: Aggregates real-time contests from Codeforces, CodeChef, HackerEarth, Topcoder, LeetCode, AtCoder.
- 🔴 **Live Indicators & Ticking Countdowns**: Real-time live status badges and `Ends in HH:MM:SS` / `Starts in HH:MM:SS` ticking countdown timers.
- 📅 **Google Calendar Direct Sync & .ICS Export**: One-click add to Google Calendar or download `.ics` event files.
- 📱 **Slide-Out Navigation Drawer**: Responsive mobile-first drawer navigation matching React Native aesthetics.
- 📅 **Monthly Interactive Calendar Grid**: View contest distribution across days.
- ⭐ **Saved / Bookmarked Contests**: Persisted locally via `localStorage`.
- 🌙 **Dark & Light Mode**: Customizable visual themes with glassmorphism UI.
- 👤 **Author Bio Screen**: Dedicated About Author section for Yash.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS Design Tokens with Dark/Light mode support
- **APIs**: Codeforces REST API + Google Calendar API + Native Web Share & iCal Generators

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/dangiyash/codecal.git
cd codecal
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
